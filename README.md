## 🚀 How to Run the Code

Since this project uses C++, you will need a compiler (like GCC/MinGW) to run the files locally.

1.  Open your terminal.
2.  Navigate to the folder containing the `.cpp` file.
3.  Compile the code:
    ```bash
    g++ main.cpp -o main
    ```
4.  Run the executable:
    ```bash
    ./main
    ```
